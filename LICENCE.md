## 🧩 About

**Throne and Liberty Grind Helper** is a comprehensive overlay for Throne and Liberty featuring a loot tracker, farming route planner, buff timer, inventory overlay, XP monitor, and grind session logger.

Based on popular tools like **TL Toolkit**, **Aion Grind Tracker**, and **Lost Ark Compass**.

---

## ✨ Features

### 🎮 Core Tools
- Loot Tracker — log drops, silver, and materials per session
- Route Planner — map efficient farming loops across zones
- Buff Timer — countdown for food, scrolls, and guild buffs
- XP Monitor — track leveling progress per hour
- Session Logger — record grind sessions and gain rates

### 🎨 Overlay & UI
- Inventory Overlay — live item count without opening menus
- Minimal HUD — transparent pane over the game window
- Custom Themes — dark and light overlay presets

### 🏋️ Grinding & Training
- Mob Respawn Timer — track named monster spawn windows
- Contract Assistant — checklist for daily and weekly contracts
- Gathering Route Sync — combine mining, logging, and fishing loops
- Drop Rate Notes — annotate zones with player-reported rates
